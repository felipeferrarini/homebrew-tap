# homebrew-tap

Homebrew tap for [PRPulse](https://github.com/felipeferrarini/prpulse), a menu bar app that tells you which GitHub pull requests need you.

```bash
brew tap felipeferrarini/tap
brew install --cask prpulse
```

> [!NOTE]
> PRPulse is not signed with an Apple Developer ID, so macOS blocks the first launch. Open it once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
